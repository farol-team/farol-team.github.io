Security
4 layers of protection
Every request, file access, and inference call is governed by declarative policy.
🌐

Network Isolation

Blocks unauthorized outbound connections. Agent can only reach approved hosts. Hot-reloadable at runtime.

📁

Filesystem Sandbox

Agent reads/writes only within /sandbox and /tmp. Nothing else. Locked at creation.

⚙️

Process Policy

Blocks privilege escalation and dangerous syscalls (Landlock + seccomp). Agent can't escape the sandbox.
